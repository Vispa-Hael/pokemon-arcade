# Local gameplay previews

These JPEGs were captured from the actual local browser game screens on 2026-10-22. They are static gameplay previews, not generated concept art or promises of unimplemented gameplay. Captures include the current game UI and, where visible, the arcade's focus toolbar. They stay local and load lazily on library cards.

- `guess.jpg`: the shared-data mystery game in its masked state.
- `pokemon-skate.jpg`: the live 3D skate park.
- `pocket-capsule-monsters.jpg`: an active turn-one board with local figures.
- `jungle-caravan.jpg`: a running crew expedition with its combat HUD.
- `arena.jpg`: the existing sibling game's sample battle.
- `chess.jpg`: the existing sibling game's 3D chessboard.

Underlying character/artwork attribution remains in the original game READMEs and `public/characters/ASSET-SOURCES.md` / `public/capsule/ASSET-SOURCES.md`. This project does not claim ownership of Pokémon characters or artwork. Future game revisions may require refreshing these screenshots.
